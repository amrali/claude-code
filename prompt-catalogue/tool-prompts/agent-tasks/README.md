Prompts for tools that manage agents and tasks.

| File | Tool Name | Description |

| [task-create-tool.md](task-create-tool.md) | `TaskCreate` | Create tasks in the task list |
| [task-get-tool.md](task-get-tool.md) | `TaskGet` | Get a task by ID |
| [task-list-tool.md](task-list-tool.md) | `TaskList` | List all tasks |
| [task-stop-tool.md](task-stop-tool.md) | `TaskStop` | Stop a running background task |
| [task-update-tool.md](task-update-tool.md) | `TaskUpdate` | Update task status/fields |
| [send-message-tool.md](send-message-tool.md) | `SendMessage` | Send a message to another agent |
