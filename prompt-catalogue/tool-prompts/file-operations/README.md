# File Operations Tool Prompts

Prompts for tools that read, write, and edit files.

| File | Tool Name | Description |
|------|-----------|-------------|
| [file-edit-tool.md](file-edit-tool.md) | `Edit` | Exact string replacement in files |
| [file-read-tool.md](file-read-tool.md) | `Read` | Read files from the filesystem |
| [file-write-tool.md](file-write-tool.md) | `Write` | Write/create files on the filesystem |
| [notebook-edit-tool.md](notebook-edit-tool.md) | `NotebookEdit` | Edit cells in Jupyter notebooks |
